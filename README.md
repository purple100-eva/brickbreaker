# Egg-cellent!

A sperm-and-egg brickbreaker, made with love for Mom 💕

Play it: https://purple100-eva.github.io/brickbreaker/

## How to play
- **Phone:** drag to aim, let go to launch, then drag to move the paddle.
- **Computer:** move the mouse to aim, click to launch. Mouse or ← → moves the paddle; space launches.

## Run locally
```
python3 -m http.server 8000
```
Then open http://localhost:8000

Change the title or the dedication at the top of `game.js`.
